# Программируемый калькулятор

Стековый (RPN) программируемый калькулятор в духе «Электроники Б3-34»: 4-регистровый стек,
16 регистров памяти, программы до 1000 шагов с метками, условными переходами, циклами
и подпрограммами. Работает полностью в браузере, без сборки и зависимостей.

## Запуск

Вариант 1 — просто открыть файл:

```bash
xdg-open calculator/index.html      # Linux
open calculator/index.html          # macOS
```

Вариант 2 — локальный сервер (нужен, если браузер блокирует локальные файлы):

```bash
cd calculator && python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000
```

Вариант 3 — **на телефоне как приложение**: готовый APK лежит в
[`apk/progcalc-debug.apk`](../apk/progcalc-debug.apk), исходники обёртки и
инструкции по сборке — в [`android/README.md`](../android/README.md).
Эти же `index.html`, `css/` и `js/` на этапе сборки копируются в `assets` APK,
поэтому браузерная и Android-версии не расходятся.

## Как считать (RPN)

Калькулятор стековый: **сначала числа, потом операция**. Операция берёт `Y` и `X`
и кладёт результат в `X`.

| Нужно        | Нажать                      | Результат |
|--------------|-----------------------------|-----------|
| 6 × 7        | `6` `В↑` `7` `×`            | 42        |
| (2 + 3) × 4  | `2` `В↑` `3` `+` `4` `×`    | 20        |
| sin 30°      | `3` `0` `sin`               | 0.5       |
| 2¹⁰          | `2` `В↑` `1` `0` `yˣ`       | 1024      |

`В↑` (Enter) — ввести набранное число в стек; без набранного числа работает как «дублировать X».

Стек виден над клавиатурой: `T Z Y X` (X — подсвечен, это текущее число).

## Программы

### Режимы

- **РЕЖИМ ПРГ** (`ПРГ`) — каждое нажатие клавиши не вычисляется, а записывается шагом
  в программу. Индикатор `ПРГ` в строке состояния горит.
- **ЗАПУСК** (`Ctrl+R`) — выполнить программу целиком.
- **ШАГ** (`F5`) — выполнить один шаг (отладка). Курсор в листинге показывает текущий шаг.
- **ШАГ С НАЧАЛА** — сбросить счётчик команд на шаг 0 и выполнить один шаг.
- **СТОП** — остановить выполнение.

Листинг справа: клик по шагу — выбрать (новая вставка попадёт после него),
`✕` — удалить шаг. Панель «Вставить шаг» позволяет собрать программу вручную:
операция, константа, метка, переход, условный переход (с веткой «иначе»),
работа с регистром, счётчик цикла, вызов/возврат подпрограммы, СТОП, комментарий.

### Шаг программы (формат данных)

Программа — массив объектов. Так она хранится в JSON и так её можно задать из консоли:

```js
{ op: 'add' }                       // операция из таблицы OPS
{ op: 'pow' }                       // Y^X
{ lit: 3.14 }                       // положить константу в X
{ label: 'L0' }                     // метка (ничего не выполняет)
{ jmp: 'L0' }  |  { jmp: 12 }       // безусловный переход (на метку или номер шага)
{ cond: 'x<0', jmp: 'L1' }          // условный переход по X
{ cond: 'x>10', jmp: 'L1', els: 'L2' }  // с веткой «иначе»
{ reg: '5', act: 'recall' }         // R5 → X          (act: recall | store | add | sub)
{ reg: '1', act: 'loop', jmp: 'L0' }// R1 − 1 → R1; если R1 ≠ 0, переход на L0 (цикл)
{ call: 'L5' }                      // вызов подпрограммы
{ ret: true }                       // возврат из подпрограммы
{ stop: true }                      // останов программы
{ flg: 3, act: 'set' }              // флаг F3 = 1      (act: set | clear)
{ cmt: 'пояснение' }                // комментарий
```

### Условия переходов

Именованные: `x=0`, `x≠0`, `x>0`, `x≥0`, `x<0`, `x≤0`, `x=1`, `x≠1`, `x>1`, `x≥1`,
`x<1`, `x≤1`, `0<x<1`, `x=π`, `F0`…`F3` (проверка флага).

Плюс любая запись вида `x <знак> <число>`: `x>10`, `x≤0.25`, `x=-3.5`, `x>=100`.

### Операции

Арифметика `+ − × ÷ yˣ ˣ√y log_y x hyp`, функции `√x ∛x x² eˣ 10ˣ ln lg 1/x |x| /−/ x!
{x} ⌊x⌋ ⌈x⌉ round int rnd`, тригонометрия `sin cos tan` и обратные (клавиша `INV`),
гиперболические `sh ch th`, константы `π e`, перевод углов `→° →rad`,
работа со стеком: `В↑` — ввести/дублировать X, `XY` — обмен X и Y, `↻R` — прокрутка стека,
`x↓` — вытолкнуть X, `C` — очистка.

Часть операций (`ˣ√y`, `log_y x`, `hyp`, `sh/ch/th`, `10ˣ`, `{x}`, `⌊x⌋`, `⌈x⌋`, `round`,
`int`, `rnd`) не вынесена на клавиши, но доступна в списке операций панели «Вставить шаг»
и из консоли: `calc.op('cbrt')`, `calc.op('logyx')` и т. д.

Режимы углов: `DEG / RAD / GRAD`. Формат вывода: `АВТО / FIX / SCI / ENG` + число знаков.

### Регистры

16 регистров `R0…R9`, `RA…RF`. Клик по ячейке регистра — вызвать его в X.
Клавиши `RS` (X → R), `RR` (R → X), `R+`, `R−` спросят номер регистра.

## Примеры программ

Выпадающий список «Примеры и хранение» загружает готовые программы:

| Пример                  | Что делает                                        | Вход |
|-------------------------|---------------------------------------------------|------|
| Сумма 1..N (цикл)       | сумма целых от 1 до N через счётчик `R1`          | N в X |
| Факториал N!            | N! циклом с накопителем `R2`                       | N в X |
| Числа Фибоначчи F(N)    | F(N) через два регистра                            | N в X |
| √x методом Ньютона      | итерации `x ← (x + S/x)/2`, 20 шагов               | S в X |
| Квадратное уравнение    | корни `a·x²+bx+c=0`; D в R4, x₁ в R6, x₂ в R7      | a,b,c в R1,R2,R3 |
| Подпрограмма CALL/RET   | 2^N через подпрограмму умножения                   | N в X |

Порядок: набрать вход → `ЗАПУСК`.

Например, сумма 1..10: `1` `0` `В↑` → `ЗАПУСК` → в X будет `55`.

## Хранение

- **СОХРАНИТЬ / ЗАГРУЗИТЬ** — библиотека программ в `localStorage`.
- **ЭКСПОРТ JSON** — скачать всю программу вместе с регистрами, флагами и настройками.
- **ИМПОРТ JSON** — загрузить такой файл обратно.
- Режим углов и формат вывода запоминаются между сессиями.

## Клавиатура

| Клавиша          | Действие                                  |
|------------------|-------------------------------------------|
| `0`–`9`, `.`     | набор числа                               |
| `Enter`          | В↑ (ввести число в стек); в режиме ПРГ — записать шаг СТОП |
| `+ - * / ^`      | сложение, вычитание, умножение, деление, степень |
| `s` `c` `t`      | sin, cos, tan                             |
| `l` `p` `q` `!`  | ln, π, √x, x!                             |
| `Backspace`      | стереть цифру (при пустом наборе — вытолкнуть X) |
| `Esc`            | сброс X и стека                           |
| `_`              | смена знака                               |
| `F5`             | шаг программы                             |
| `Ctrl+R`         | запуск программы                          |
| `Ctrl+S`         | сохранить программу в библиотеку          |

## Программирование из консоли / Node.js

Ядро не зависит от DOM, поэтому его можно использовать как библиотеку.
В браузере движок доступен как `window.calc`:

```js
calc.enter(2); calc.enter(10); calc.op('pow');   // 1024
calc.setProgram([{ lit: 5 }, { op: 'fact' }, { stop: true }]);
calc.run();
calc.x();                                        // 120
```

В Node.js:

```js
const PC = require('./js/engine.js');
const c = new PC.Calculator();
c.angleMode = 'DEG';
c.enter(30).op('sin');        // 0.5
```


## Тесты

```bash
node calculator/test/engine.test.js    # 41 проверка ядра
node calculator/test/app.smoke.js      # 29 проверок интерфейса
python3 android/verify_apk.py          # 39 проверок собранного APK
```

Все три самодостаточны (без внешних библиотек, нужен только Node.js или Python 3)
и возвращают ненулевой код при провале. Smoke-тест запускает интерфейс на
мини-DOM-шимме: проверяет построение клавиатуры и листинга, нажатия кнопок,
режим ПРГ, пошаговое выполнение, форматы вывода, localStorage и оба пути
экспорта (blob в браузере и нативный мост в APK).
